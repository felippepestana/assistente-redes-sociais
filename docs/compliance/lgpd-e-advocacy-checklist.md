# Checklist LGPD E Advocacy

## LGPD

- [ ] Informar finalidade da coleta.
- [ ] Solicitar apenas dados necessarios.
- [ ] Registrar consentimento quando usado como base.
- [ ] Manter politica de privacidade acessivel.
- [ ] Proteger anexos em storage privado.
- [ ] Evitar exposicao publica de dados de leads.

## Advocacy

- [ ] Evitar promessa de resultado.
- [ ] Evitar urgencia artificial ou apelo mercantilista.
- [ ] Publicar apenas credenciais verificaveis.
- [ ] Usar CTA informativo e sobrio.
- [ ] Revisar depoimentos, cases e provas antes de publicar.

# Runbook Google Drive

## Objetivo

Criar a estrutura operacional para documentos de onboarding, credenciais, midia aprovada e relatorios.

## Estrutura

Pasta raiz: `Assistente de Redes Sociais`

Subpastas:

- `01 Onboarding`
- `02 Credenciais`
- `03 Documentos`
- `04 Midia Aprovada`
- `05 Relatorios`

## Regras

- Evitar nomes de arquivo com dados pessoais desnecessarios.
- Restringir acesso por necessidade.
- Separar credenciais/documentos sensiveis de materiais publicaveis.
- Registrar o link da pasta raiz em `docs/operations/external-artifacts.md`.
